¿Windows o Mac? Aquí trabajaremos hoy

La terminal es una ventana donde escribimos comandos. No hay que temerle: hoy solo copiaremos y pegaremos.

Windows
Buscar → "PowerShell"
Se reconoce por el prompt:
PS C:\Users\tú>
No uses CMD ni la versión "x86".
Mac
Cmd + Espacio → "Terminal"
Se reconoce por el prompt:
tu-mac ~ %
Termina en el símbolo %.

Los 3 errores más comunes

Si algo falla, casi siempre es uno de estos

  • 01
    "no se reconoce" / "command not found" justo después de instalar. Cierra y vuelve a abrir la terminal: recarga el PATH. Es la causa número uno.
  • 02
    Python no aparece en Windows. Olvidaste marcar "Add Python to PATH". Reinstala desde python.org marcando esa casilla.
  • 03
    PowerShell bloquea un script. Ejecuta una vez: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, reabre la terminal y reintenta.
