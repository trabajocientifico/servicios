R, RStudio, Python, Node.js y FreeBuff. Al final de la sesión cada uno escribe un comando y el computador contesta con un número de versión. Ese número es la única prueba de que quedó bien instalado.

EL ORDEN IMPORTA

Cada instalación
depende de la anterior

No es una lista de tareas: es una cadena. Si se saltan un eslabón, el siguiente falla y parece que "el programa está dañado".

02RStudioLa interfaz. Busca un R ya instalado; si no lo halla, no abre.NECESITA 01

Aclaración de entrada: FreeBuff es un agente de terminal que se distribuye por npm. Python lo instalamos porque lo van a necesitar para análisis de datos, no porque FreeBuff lo pida.
01 · EL MOTOR

Instalar R

  1. Abre el navegador y entra a cran.r-project.org
  2. Clic en Download R for Windows (o for macOS según el equipo)
  3. Clic en base → Download R 4.x.x for Windows
  4. Ejecuta el archivo .exe descargado
  5. Acepta todo por defecto: Siguiente → Siguiente → Instalar
Por qué no hay que tocar nada: las opciones por defecto dejan R en la ruta que RStudio busca automáticamente. Cambiar la carpeta es el origen del error "R no encontrado".
consola de R — verificación
Se escribe en la consola de R, no en Windows
02 · LA INTERFAZ

Instalar RStudio

  1. Entra a posit.co/download/rstudio-desktop
  2. Descarga RStudio Desktop, la versión gratuita
  3. Ejecuta el instalador con las opciones por defecto
  4. Abre RStudio: detecta R solo, sin configurar nada
  5. Escribe version en la consola y presiona Enter
R y RStudio no son lo mismo. R es el motor; RStudio es el tablero. Desinstalar R deja RStudio inservible, aunque el ícono siga ahí.
RStudio — panel Console
Panel inferior izquierdo
03 · LA TRAMPA DE LA CASILLA

Instalar Python

  1. Entra a python.org/downloads y descarga la versión estable
  2. Ejecuta el instalador y NO des clic todavía
  3. Marca Add Python to PATH abajo del todo
  4. Ahora sí: Install Now
  5. Cierra la terminal y ábrela de nuevo
PRUÉBALO: ESTA ES LA CASILLA
PowerShell — verificación

04 · EL GESTOR DE PAQUETES

Instalar Node.js

  1. Entra a nodejs.org
  2. Descarga la versión LTS, no la "Current"
  3. Instala con las opciones por defecto
  4. Cierra y vuelve a abrir la terminal
  5. Comprueba con node --version y npm --version
LTS significa soporte a largo plazo: es la versión estable. La "Current" trae novedades y también fallas que no queremos en clase.
Si dice "no se reconoce": no reiniciaste la terminal. La terminal lee las rutas solo al abrirse.
PowerShell — verificación

05 · EL AGENTE

Instalar y abrir FreeBuff

  1. En la terminal: npm install -g freebuff
  2. El -g lo deja disponible desde cualquier carpeta
  3. Entra a tu proyecto: cd C:\Users\TuUsuario\Documents\mi_proyecto
  4. Escribe freebuff y Enter
  5. Indexa la carpeta y abre un chat dentro de la terminal
Sin API key, sin tarjeta, sin archivo de configuración. Es gratuito porque muestra anuncios de texto entre respuestas del agente. Los modelos se cambian con /model.
El error clásico: intentar pip install freebuff. No existe en PyPI: se instala con npm.

CIERRE · DIAGNÓSTICO

Cuando algo falla,
casi siempre es esto

"NO SE RECONOCE EL COMANDO"

Causa: no marcaron Add to PATH, o no reiniciaron la terminal. Arreglo: cerrar la terminal y abrirla otra vez. Si persiste, reinstalar Python marcando la casilla.

RSTUDIO NO ABRE

Causa: instalaron RStudio antes que R, o cambiaron la carpeta de R. Arreglo: instalar R desde CRAN con las opciones por defecto y volver a abrir RStudio.

NPM NO EXISTE

Causa: creen que instalaron Node pero cerraron el instalador antes de terminar. Arreglo: reinstalar la versión LTS y reabrir la terminal.

FREEBUFF NO ARRANCA

Causa: lo corren fuera de una carpeta de proyecto, o lo buscaron con pip. Arreglo: cd hasta el proyecto y correr freebuff.
